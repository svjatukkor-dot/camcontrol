# DropCam — Програма для керування камерами та підключення телефона на ПК

**DropCam** (на базі рушія **CamControl**) — програма для Windows 10 / Windows 11 та веббраузера, яка перетворює смартфон на вебкамеру для ПК (як DroidCam) і дозволяє в реальному часі налаштовувати параметри будь-яких підключених USB-камер і вебкамер.

---

## Основні можливості

- **Автоматичне виявлення камер**: пошук USB-вебкамер, карт відеозахоплення та підключених пристроїв у реальному часі.
- **Підключення телефона по Wi-Fi (QR-код / 6-значний код)**: трансляція відео та мікрофона з Android або iPhone прямо у програму без встановлення сторонніх драйверів.
- **Дистанційне керування телефоном з ПК**: перемикання тильної/передньої камери, керування спалахом (ліхтариком), мікрофоном, поворотом (0° / 90° / 180° / 270°) та роздільною здатністю.
- **Гібридне налаштування зображення**: яскравість, контрастність, насиченість, різкість, експозиція, баланс білого (K), масштаб (Zoom) та фокус — через апаратний драйвер або через програмну обробку кадрів у реальному часі.
- **Зміна формату наживо**: вибір роздільної здатності (від VGA до 4K UHD) та частоти кадрів (15 / 24 / 30 / 60 FPS) без перезапуску програми.
- **Профілі та JSON**: збереження індивідуальних профілів для кожної камери, автоматичне підвантаження при перемиканні, експорт та імпорт у `.json`.
- **Діагностика та фотознімки**: вимірювання фактичного FPS, матриця параметрів драйвера, порівняння «До / Після» та швидкі знімки у форматі PNG.

## Як запустити програму

### Спосіб 1: Запустити у веббраузері локально (включаючи Wi-Fi міст для телефона)

> Підходить для миттєвого запуску та тестування підключення телефона по Wi-Fi без компіляції `.exe`.

**Вимоги:** встановлений [Node.js LTS](https://nodejs.org/) (версія 20 або новіша).

1. Відкрийте термінал (PowerShell або Command Prompt) у папці з проєктом.
2. Встановіть залежності:
   ```bash
   npm install
   ```
3. Запустіть сервер і вебінтерфейс:
   ```bash
   npm run dev
   ```
4. Відкрийте у браузері адресу:
   ```text
   http://localhost:3000
   ```
5. Для запуску у production-режимі:
   ```bash
   npm run build
   npm start
   ```

---

### Спосіб 2: Отримати готовий Windows `.exe` через GitHub Actions (найпростіший спосіб)

> Не потребує встановлення Rust чи компілятора Visual Studio на ваш комп'ютер.

1. Завантажте цей проєкт у власний репозиторій на **GitHub**.
2. Перейдіть у вкладку **Actions** вашого репозиторію.
3. Оберіть workflow **Windows installer** (`.github/workflows/release-windows.yml`) і натисніть **Run workflow** *(або створіть тег релізу `git tag v1.0.0 && git push origin --tags`)*.
4. Після завершення збірки завантажте готовий інсталятор **`.exe`** (NSIS) або **`.msi`** зі сторінки **Releases** або розділу **Artifacts** та запустіть його на Windows 10 / Windows 11.

---

### Спосіб 3: Зібрати Windows `.exe` локально на своєму ПК

**Системні вимоги (Windows 10 / 11 x64):**
- [Node.js LTS](https://nodejs.org/) (v20+)
- [Rust (stable)](https://rustup.rs/) з обраним тулчейном **MSVC**
- **Microsoft C++ Build Tools** (компонент «Розробка класичних програм на C++» у Visual Studio Installer)
- **WebView2 Runtime** (уже встановлено в Windows 11 і більшості систем Windows 10)
- **Tauri CLI v2**:
  ```powershell
  cargo install tauri-cli --version "^2.0.0" --locked
  ```

**Команди для збірки `.exe`:**
```powershell
npm install
npm run build
cargo tauri build --bundles msi,nsis
```

**Де знайти зібрані файли після завершення:**
- Інсталятор Windows (`.exe`): `src-tauri/target/release/bundle/nsis/DropCam_1.0.0_x64-setup.exe`
- Пакет MSI (`.msi`): `src-tauri/target/release/bundle/msi/DropCam_1.0.0_x64_en-US.msi`
- Прямий виконуваний файл без інсталятора: `src-tauri/target/release/camcontrol.exe`

Для запуску в режимі розробки десктопного вікна використовуйте:
```powershell
cargo tauri dev
```

## Як підключити телефон як вебкамеру

### Через Wi-Fi (QR-код або 6-значний код)
1. Запустіть **DropCam** на ПК (`npm run dev` або відкрийте розгорнуту вебверсію).
2. На головному екрані з'явиться **QR-код** і **6-значний код підключення**.
3. Відскануйте QR-код камерою телефона *(якщо комп'ютер і телефон у різних мережах або відкрито захищене прев'ю, переконайтеся, що на телефоні виконано вхід або використовується публічна адреса сервера)*.
4. Надайте браузеру телефона дозвіл на камеру — відео автоматично з'явиться в DropCam на ПК.

### Через USB-кабель
- **Android 14+ (без сторонніх програм):** підключіть кабель → відкрийте панель сповіщень на телефоні → натисніть «Заряджання через USB» → оберіть режим **«Вебкамера» (Webcam)** → натисніть **«Оновити камери»** у DropCam.
- **Windows 11 («Зв'язок зі смартфоном»):** увімкніть використання камери телефона в *Параметри Windows → Bluetooth і пристрої → Мобільні пристрої*.
- **У нативному `.exe` (через ADB):** при увімкненому «Налагодженні по USB» (USB Debugging) у Windows-версії доступна перевірка підключених Android-пристроїв через `adb devices`.
